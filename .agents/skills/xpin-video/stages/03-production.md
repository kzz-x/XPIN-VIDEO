# 03｜逐镜制作与工程修改（AE / Blender / HTML / 二维 / 三维）

**输入只需当前镜头卡、已定参考/资产及前后镜头的衔接点。** 高完成度镜头先做 Hero 关键帧，再完成运动；复杂镜头单独执行，合片时统一视觉与节奏。

## 安全执行

- 已有工程：先读取**任务涉及**的真实文件、场景/合成、选中对象、动画和依赖；**首次修改前，在原目录外复制完整可恢复的工程和必要依赖，检查备份可用**。原工程文件名与位置不动。最小 Patch，只改用户指定部分；保护人工关键帧、曲线、父子级、材质、表达式、素材路径、Marker。写后读回/比对受影响项和未授权区域。无法备份则停止写入并说明。
- 新镜头：确认参考、真实结构、画幅及素材。简单动画不搭复杂工程；多对象共享运动/模板化时先设计控制关系，避免重复散落关键帧。
- 执行能力以实际可用工具为准；未连接 AE/Blender 不声称已操作。问题出现再查相应文档或故障，不为了「完整」预读无关源码。

## 按媒介直接做（规则已内置，无需跳旧仓）

- **AE｜二维、2.5D、字幕/图表/合成：** 少量对象优先原生 Shape/Text/Animator、Mask/Matte、Repeater、关键帧；有共享运动才用 Null/Parent/Precomp/Controller，复杂关系用表达式或 JSX/MCP。修改「选中层」必须现场读选区。中文图层/控件，底层 API 保持稳定标识；不机械套 Easy Ease、不默认文字渐显缩放。使用 Engine Room 时**先开 AE 并确认 MCP，再开 PR**，连接异常先排除 PR 干扰。
- **Blender｜实体 3D/结构/写实/复杂灯光：** 保留真实对象、Collection、材质与 Action。共享运动用 Empty/Parent/Constraint，调节用 Custom Properties/Driver/Delta Transform，动画用少量关键姿态 + F-Curve；只有需要时做 N Panel、Geometry Nodes、Camera/Focus Rig。除烘焙/模拟外避免逐帧 Transform Key；相机与主体互相配合，复杂路径允许留给人工微调。
- **HTML / Three.js / WebGL｜实时可调、技术渲染与信息动效：** 场景、控制、时间轴和输出分离；保持单一时间源，同一时间 `t` 的 Camera、模型、标注、特效状态可重复求值。提供可拖动时间线、Marker、播放/暂停、参数保存与可见的预览结果；导出尽量确定性逐帧。用户要单 HTML 就维持单 HTML，除非维护或性能明显要求拆分。
- **真实素材 / 独立元素 / AI 片段：** 使用 02 已确认的候选与准确文件；素材类保留来源/风险，元素类保留独立 Alpha/图层/轴心，生成片段不承担必须精确的品牌字、数字或可编辑交互。没有关键准确资产先补，不能用假结构顶替。

## Motion、控件和验收

艺术决定动作性格；结构/旋转中心/安全路径先于曲线。灵活使用 Timing/Spacing、缓动、Anticipation、Overshoot、Stagger、Follow Through、停顿与节奏反差；相机、主体、文字和光应编舞协同。转场优先真实的空间/运动/遮挡/尺度关系，Opacity 只是辅助；避免 PPT 式平移淡入和无意义特效。

有口播以真实音频/时间码为准；否则据字数粗估。镜头边界、关键词、转场与音效点做**可微调 Marker**。复杂运动统一时间线，支持 Seek、暂停、预览与输出一致。

**差点控件：** 用户以后真会改的 5–8 个参数置顶（主体/素材、位置大小、速度、强度、相机、颜色等），其余分类折叠；全中文，英文术语附解释，调整尽量实时生效。共享动作在父级，单体保留局部 Override；不要为了控件牺牲画面，也不要为简单镜头做大编辑器。

**交给 Codex 的提示词短句即可：** `表达目标 + 已定参考/资产 + 主动作/节奏 + 锁定项 + 可编辑交付 + 验收`。默认 P2 允许自主实现；局部改动用 P3：`先异地备份，只改 X，保持其他不变，检查回归`。不讲一大段施工教程。

**当前镜头完成：** 回读真实工程、对照参考看起/中/末帧及过渡、核对可编辑性和独立控件；只报告实际改了什么、预览位置和仍未通过的项。不因脚本返回成功就认定画面达标。
