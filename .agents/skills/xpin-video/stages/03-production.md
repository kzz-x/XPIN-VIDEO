# 03｜逐镜制作与工程修改（AE / Blender / HTML / 二维 / 三维）

**输入只需当前镜头卡、已定参考/资产及前后镜头的衔接点。** 高完成度镜头先做 Hero 关键帧；运动品味是难点时可先做低成本灰盒预演，再完成视觉；复杂镜头单独执行，合片时统一视觉与节奏。

## 安全执行

- 已有工程：先读取**任务涉及**的真实文件、场景/合成、选中对象、动画和依赖；**首次修改前，在原目录外复制完整可恢复的工程和必要依赖，检查备份可用**。原工程文件名与位置不动。最小 Patch，只改用户指定部分；有未保存的人工改动时备份必须覆盖最新状态，不将旧 Auto-Save 冒充本轮备份；保护人工关键帧、曲线、父子级、材质、表达式、素材路径、Marker。写后读回/比对受影响项和未授权区域；AE/MCP/JSX 报错或超时先核真实写入状态，不盲目重跑可能已部分完成的脚本。无法备份则停止写入并说明。
- 新镜头：确认参考、真实结构、画幅及素材。简单镜头即使从零制作，也不强制 Null/CTRL/Rig；只有真实的共享运动、动态关系或复用需求才先搭必要骨架。动效应先明确谁跟随、携带、指向谁，以及整体/局部运动分别由谁控制，不能靠多层复制近似关键帧假同步。
- 模板化与普通修改不同：源工程/正式模板保持只读，另建模板开发副本并核对字体、插件、贴图、模型、音频等必要依赖与许可；缺失依赖先报告影响，不擅自删效果/换插件；用户当前工作文件路径不改变。执行能力以实际可用工具为准；未连接 AE/Blender 不声称已操作。问题出现再查相应文档或故障，不为了「完整」预读无关源码。

## 按媒介制作

- **AE｜二维、2.5D、字幕/图表/合成：** 少量对象优先原生 Shape/Text/Animator、Mask/Matte、Repeater、关键帧；有共享运动才用 Null/Parent/Precomp/Controller，复杂关系用表达式或 JSX/MCP。修改「选中层」必须现场读选区。中文图层/控件，底层 API 保持稳定标识；不机械套 Easy Ease、不默认文字渐显缩放。使用 Engine Room 时**先开 AE 并确认 MCP，再开 PR**，连接异常先排除 PR 干扰。
- **Blender｜实体 3D/结构/写实/复杂灯光：** 保留真实对象、Collection、材质与 Action。共享运动用 Empty/Parent/Constraint，调节用 Custom Properties/Driver/Delta Transform，动画用少量关键姿态 + F-Curve；只有需要时做 N Panel、Geometry Nodes、Camera/Focus Rig。除烘焙/模拟外避免逐帧 Transform Key；相机与主体互相配合，复杂路径允许留给人工微调。
- **HTML / Three.js / WebGL｜实时可调、技术渲染与信息动效：** 场景、控制、时间轴和输出分离；保持单一时间源，同一时间 `t` 的 Camera、模型、标注、特效状态可重复求值，随机粒子/纹理也须固定种子或按 `t` 重建。提供本任务真正需要的可调图层/关键帧、Marker、拖动时间线、播放/暂停、保存与重开；**进度条不等于关键帧编辑，localStorage/导出参数不等于完整可重开工程**。实际能修改什么就交付什么，导出尽量确定性逐帧；编辑视图与纯画面录制分别按目标画幅核对，控件不得挤压/遮挡舞台，默认预览不应停在无意的空白帧。用户要单 HTML 优先交单文件；外部字体、CDN、模型等运行依赖须固定可用版本并留离线替代，避免交付后缺字/黑屏；内部职责复杂或反复修改互相污染时允许模块化开发，再提供便携单文件产物。
- **数据 / 图表 / 信息动效：** 真实数值集中于一份可替换数据源，记录出处、时间范围、单位、测试条件及实测/预测属性；数值、标签和图形从同一源生成。柱图不歪曲零基线、折线不把缺失值当零、百分比/百分点/倍率不混用，不为填满画面编数据。
- **真实素材 / 独立元素 / AI 片段：** 使用 02 已确认的候选与准确文件；素材类保留来源/风险，元素类保留独立 Alpha/图层/轴心，生成片段不承担必须精确的品牌字、数字或可编辑交互。没有关键准确资产先补，不能用假结构顶替；导入 GLB/可复用组件须实际检查层级、轴心、动画 Clip、贴图与替换接口，尤其区分科普示意与厂商真实结构。

## 创意与运动数据的分工

有粗工程/运动视频（Previs）与高质量目标参考（Target）时，**文案锁含义，Previs 锁主体关系、路径/遮挡/节拍，视觉锚点锁成品外观**；目标案例提供构图、材质、运镜与节奏质量标杆。粗视频里的占位物可以重设计，不得一边要求「旧外观全保留」一边要求「整体重做」。目标若有源工程，优先学习真实 Camera、Curve、Shader/材质和层级；借用镜头配方时核对**对应的动态预览与实际源码**，保留决定手感的运动关系/时序及已知坑，再换成当前主体和设计语言；原样例参数不等于当前镜头已验收。按效果、效率和可编辑性选渲染器，不强制使用原软件。跨 AE/PR/Resolve/HTML 交接先问最终宿主与将来需要改哪些参数：可保留原工程/参数化模板则优先保留；复杂部分可烘焙为带 Alpha 的视频/图像序列，文字和数据继续可编辑，不承诺不同格式间无损互转。

## Motion、控件和验收

艺术决定动作性格；主动作/需要人工精修的 Graph 优先真实关键帧，持续微动与跟随优先关系/短表达式；整体变化上移父级，单体微调保持独立（必要时 value + offset），不让控件覆盖原动画。结构/旋转中心/安全路径先于曲线；路径（去哪）与速度曲线（怎么走）分开控制。灵活使用 Timing/Spacing、缓动、Anticipation、Overshoot、Stagger、Follow Through、停顿与节奏反差；相机、主体、文字和光应编舞协同。转场优先真实的空间/运动/遮挡/尺度关系，Opacity 只是辅助；避免 PPT 式平移淡入和无意义特效。

有口播先用当前工程已有 Marker；不够时才分析**当前时间线实际使用的音频区间**（含剪辑/变速/嵌套时间映射），按语义聚成 Beat 后写回可编辑 Marker，保留用户原有 Marker；无口播再据字数粗估。不要为几秒口播读取/渲染整条大型 MP4。镜头边界、关键词、转场与音效点做**可微调 Marker**。复杂运动统一时间线，支持 Seek、暂停、预览与输出一致。

**差点控件：** 优先复用已有 CTRL，不新建平行控制系统；用户以后真会改的 5–8 个参数置顶（主体/素材、位置大小、速度、强度、相机、颜色等），其余分类折叠；全中文，英文术语附解释，调整尽量实时生效。做成模板时保留默认值/重置入口，高频项应能迅速定位。共享动作在父级，单体保留局部 Override；用少量有意义的 Key + Curve，动态录制则先平滑/降噪再精简，不用逐帧密集 Key 冒充流畅；不要为了控件牺牲画面，也不要为简单镜头做大编辑器。

**交给 Codex 的提示词短句即可：** `表达目标 + 已定参考/资产 + 主动作/节奏 + 锁定项 + 可编辑交付 + 验收`。默认 P2 允许自主实现；局部改动用 P3：`先异地备份，只改 X，保持其他不变，检查回归`。不讲一大段施工教程。

**当前镜头完成：** 收到反馈先辨别信息/素材、构图、Motion 或输出哪层出错，从最早出问题的一层修正，避免末端叠特效补丁。回读真实工程、按 Marker/动作落点选择少量关键帧对照参考；图像定位症状，实际工程属性/层级定位原因，连续运动的手感仍看视频/前台预览、核对可编辑性和独立控件；只报告实际改了什么、预览位置和仍未通过的项。不因脚本返回成功就认定画面达标。长期开工反复修改的工程可留一份极短的「根合成/控件/素材槽/依赖/人工精修区」索引，下次先读索引和目标对象，若与工程实际不符则以工程为准；一次性简单镜头不建档。生成片段若重复失败，先换参考/运动机制或降低非关键复杂度，不靠加长 Prompt 盲重试；改变已锁定媒介或核心交付能力必须先获用户同意。
