# 03｜逐镜制作与工程修改（AE / Blender / HTML / 二维 / 三维）

**输入：** 当前镜头卡、已锁参考/资产及邻镜衔接。Hero 关键帧先达标；运动难点可先灰盒预演，再做最终视觉；复杂镜头逐镜做，合片统一审美和节奏。

## 安全执行

- **已有工程：** 只读任务涉及的真实状态（文件、选区、场景/合成、动画、依赖）。首次写入前在原目录外备份**最新工程与必要依赖**，确认可恢复，原文件位置不变；保护未保存的人工修改。最小 Patch，保留无关关键帧/曲线、父子级、材质、表达式、Marker 和素材路径；写后回读并检查未授权区域。失败、超时或中断先核已有产物与版本，完整就接续；返工另存版本与原因，不让旧结果覆盖新成果。无法备份则停止写入。
- **新镜头：** 确认画幅、参考、真实结构和素材；确有共享运动或复用需求才搭 CTRL/Rig。先定 Follow/Carry/Target 等对象关系与局部 Offset，不复制多套 Key 假同步。
- **模板：** 正式模板只读，在副本上开发；核对字体、插件、模型、贴图、音频与授权。缺依赖先说明，不擅自删除效果或替换插件。只使用实际可用工具；未连接 AE/Blender 不称已操作；故障资料按需查。

## 按媒介制作

- **AE：** 简单图形、UI、字幕优先原生 Shape/Text/Effects、Mask/Matte、关键帧；复杂共享关系再用 Null/Parent/Precomp、表达式或 MCP/JSX。选中对象现场读；重要目标结合 AI_ID、合成名、图层名/类型定位，不依赖图层索引。中文可见命名、底层稳定 API 标识；曲线匹配动作，不机械套 Easy Ease。Engine Room **先开 AE 确认 MCP，再开 PR**，异常先排 PR 干扰。
- **Blender：** 保留对象、Collection、材质与 Action；共享运动用 Empty/Parent/Constraint，调节用 Custom Properties/Driver/Delta Transform，主动作少量 Key＋F-Curve；除追踪/模拟/烘焙，不用密集逐帧 Transform Key。N Panel 是入口，核心参数须随 .blend 原生保存；Camera/Focus Rig 按需搭建，复杂 Graph 可留给人工精修。
- **HTML / Three.js / WebGL：** Scene、Controls、Timeline、Output 分工；复杂新效果先独立验证再接入共享 Camera/Timeline/Recording，多效果合成隔离 CSS/全局状态。单一时间源驱动相机、模型、标注、特效，随机效果固定种子或按时间可复现，Seek/暂停/录制一致。按任务提供真正可用的关键帧、Marker、时间线与保存重开；**进度条不等于关键帧编辑，localStorage/参数导出不等于完整可重开工程**。编辑界面与纯画面录制分别核画幅、遮挡、默认首帧和逐帧输出。用户要求单 HTML 就交便携单文件；必要时可先模块化开发，外部字体/CDN/模型固定可用版本并备离线方案。
- **数据与图表：** 一份可替换数据源驱动数值、标签和图形；注明出处、日期、单位、测试条件及实测/预测。不编数，不误导性截断坐标轴，不把缺失当零或混淆百分比、百分点、倍率。
- **真实素材 / 元素 / AI 片段：** 使用 02 阶段已核的文件，保留来源、风险、独立 Alpha/图层/轴心和可替换接口。GLB 须核层级、轴心、贴图、动画 Clip；示意结构不冒充真实厂商结构。精确文字/数字/品牌信息尽量留在可编辑层。

## 创意、Motion 与交接

**文案锁事实；粗工程/运动预演锁主体关系、路径、遮挡和节拍；视觉锚点锁最终构图、材质与光。** 粗稿占位物可重设计，已锁关系不可擅改。目标有源工程时先查 Camera/Curve/Shader/层级；借镜头配方要对照实际动态预览和源码，保留机制/节奏/已知坑，不把示例参数当本镜头验收。跨 AE/PR/Resolve/HTML 交接由最终宿主及后续手改需求决定：优先保留原生工程/参数化能力，复杂部分可带 Alpha 局部烘焙、文字数据保留可编辑，不承诺无损互转。

**Motion：** 主动作留少量可调 Key/Graph，持续微动与对象关系用表达式/Driver；共享动作在父级，个体留局部 Override。先核结构、转轴、路径，再调速度曲线；Timing、Anticipation、Overshoot、Stagger、Follow Through 和停顿按叙事使用，不统一套模板。相机、主体、文字、光共同编舞；转场优先运动、空间、遮挡与尺度联系，避免 PPT 式平移淡入。

**口播同步：** 优先沿用已有 Marker；不够时只分析当前时间线**实际使用的音频区间**（含剪辑、变速、嵌套时间映射），按语义补可编辑 Beat/Marker；无音频再粗估，不为几秒口播处理整条大 MP4。统一时间线支持 Seek/暂停/输出一致；多镜头/预设有独立基础状态和覆盖顺序，切换从当前可见姿态接入，不能遗留旧参数或惯性。

**差点控件：** 仅暴露以后真会频改的项，优先复用既有 CTRL；常用 5–8 项置顶（主体/素材、构图、机位、速度、强度、颜色等），其余中文分类折叠，必要英文附中文解释。模板可重置；共享与局部调节分离，录制曲线先平滑再精简。不为简单镜头搭大型编辑器。

**Codex 重点版：** 表达目标＋已定参考/资产＋主动作/节奏＋锁定项＋可编辑交付＋验收。默认 P2 自由实现；局部 P3 指定备份、改动范围、保持项和回归，不写长施工教程。

**当前镜头完成：** 反馈先定位事实/素材、构图、Motion、输出哪一层最早出问题，从根因修。按 Marker/关键动作选少量静帧对标，再看真实视频手感和工程层级、控制与可编辑性；脚本成功不等于画面达标。长期项目可留极短的合成/控件/素材槽/依赖/人工精修索引，以真实工程为准；简单镜头不建档。AI 片段反复失败先换参考或运动机制，不靠拉长 Prompt 盲重试；变更已锁媒介或核心交付能力须先获同意。
