# 03｜制作与工程修改

按**当前交付物及实际依赖**采用相关媒介要求。复杂镜头先锁视觉目标与主体运动，必要时灰盒预演结构、路径与节奏；重点镜头逐个达标。

## 工程保护与执行

- **已有工程：** 先读取相关场景、对象、动画及依赖；修改前在原目录外备份最新可恢复版本，保护未保存的人工改动。最小范围修改，保留无关关键帧/曲线、父子级、材质、表达式、Marker 和素材路径；改后回读验证。中断或失败先检查现有产物，能续做就续做；返工保留版本，避免旧结果覆盖新成果。无法恢复备份时先停止写入。
- **新制作：** 按实际关系决定工程层级；共享运动建立 Parent/Follow/Target，个体保留独立 Offset，避免用重复关键帧假同步。
- **现有模板：** 在副本中开发，核对插件、模型、贴图等依赖及授权，保留已有功能。

## 按交付物选择

- **硬件结构 / GLB：** 依据可信资料还原具体型号、零件比例、位置、连接和装配关系；重要部件独立命名且轴心正确。需要拆解时制作可独立调用的标准 glTF 动画 Clip；导出后重新加载，检查层级、材质、动画与任意时间定位。结构资产与渲染风格分离，方便后续科普交互。
- **AE：** 简单动画优先原生层与效果，复杂关系再用 Null/Parent/Precomp、表达式或脚本。修改前定位真实选中对象，用稳定标识结合合成名、图层名/类型核实目标；中文可见命名，主运动保留可调曲线。使用 Engine Room 时先启动 AE 确认连接，再启动 PR。
- **Blender：** 保持对象、Collection、材质、Action 清晰；按需使用 Empty/Parent/Constraint、Custom Properties/Driver/Delta Transform 和少量可调 Key＋F-Curve，共享动作与局部调节分开。需要交付可编辑 Blender 工程时，控制数据随工程保存，N Panel 只是入口；导出其他格式时验证目标格式实际支持的动画。
- **HTML / Three.js：** Scene、Controls、Timeline、Output 分工；相机、模型、标注、特效用同一时间源，随机效果固定种子或按时间确定，确保 Seek/暂停/逐帧录制一致。复杂特效先隔离验证再集成；区分实际关键帧编辑、参数保存与工程完整重开。需要纯画面录制时检查 WebGL/DOM/SVG、字体、混合层、画幅及真实文件输出；按需求打包单 HTML 或明确依赖。
- **数据与素材：** 图表采用可追溯、可替换的数据，保留来源、时间、单位和测试口径。外部素材核使用范围；元素保留合成所需 Alpha、分层、轴心及替换能力，示意内容明确标识。

## 动画、控制与交接

- **Motion：** 先核结构、转轴、跟随关系与运动路径，再设计节奏、缓急、预备动作、错落、惯性与停顿。主动作保留少量可调关键帧/曲线，持续运动按需程序化；共享 Motion 在父级，个体留局部 Override。相机与主体共同编舞，避免镜头运动掩盖信息。
- **口播同步：** 沿用已存在的 Marker；需要补点时仅分析实际使用的音频片段，按语义、停顿和节拍同步。多个镜头/预设切换时处理当前姿态与状态延续。
- **可编辑控件：** 影响结果且后续可能手调的重要参数提供入口，高频项前置，低频重要项中文分类折叠；调参实时预览，并能重置。沿用现有控制关系。
- **跨软件交接：** 依据最终宿主与修改需求保留原生工程或可编辑参数；复杂效果可局部烘焙为带 Alpha 的素材，文字、数据等尽量保留可编辑。
- **Codex 执行：** 只传当前目标、参考与素材、核心动作、交付格式和验收；局部修改明确保护范围，具体实现保留自主选择。
- **验收：** 结合关键时刻截图与实际播放检查事实、构图、运动、交互、可编辑性和导出结果。从根因修复并只返工受影响部分；修改已锁定的核心交付要求需先确认。
