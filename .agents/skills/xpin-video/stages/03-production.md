# 03｜逐镜制作、现有工程修改（Codex）

**只拿当前镜头卡 + 全局视觉/音频约束 + 前后镜头的衔接信息执行。** 全片可以规划，复杂镜头不要一口气全做；可由子 Agent 分镜并行，但每镜独立验收后再合片。

## 起手

- **已有工程：** 先实际读取指定文件/选中对象/层级和当前版本。**写入前将完整原工程及必要依赖复制到另一个位置（如独立 backups 目录，带时间戳）**，核实备份可读；原工程的文件名和位置不变。优先局部 Patch；用户没要求改的画面、参数、轨道、关键帧、人工微调、素材链接都保持不变。不能备份时明确阻塞，不冒险直接覆盖。
- **新镜头：** 用已确认参考、可用模型/素材、口播及镜头卡开始。先做一个 Hero/代表镜头的关键帧对照参考，确认上限，再扩展时序。
- **专业路由（仅在确实操作时读取）：** AE→[XPIN-AE-SKILL](https://github.com/kzz-x/XPIN-AE-SKILL) 的 `AGENTS.md`；Blender→[XPIN-Blender-Skill](https://github.com/kzz-x/XPIN-Blender-Skill) 的 `AGENTS.md`；真实素材/元素/AI片段→[差点后期](https://github.com/kzz-x/chadian-post-GTP-project) 的对应单一 reference。默认 Mini/最少模块，复杂才 Full；**不扫完整旧仓库**。AE 使用 Engine Room 时先启动 AE、验证 MCP，再开 PR。

## 给 Codex 的短任务（默认 P2）

`要表达什么｜最终画面和参考｜现成资产/准确性｜主动作、口播节拍及前后衔接｜已锁定项与可编辑交付｜验收重点`。

**描述目标，不教授实现步骤。** 自由决定 AE/Blender/HTML、运动实现、特效及优化方法；除非用户选定软件、格式或有真实能力约束。精确局部修改用 P3：`只改 X，保持 Y/Z 不变，修改前备份，验收回归`。第一次偏差只收紧失败维度，不追加一页新规则。

## 成片级 Motion 与可编辑性

- 路径/结构/旋转轴正确先于曲线；主体、Camera、文字/标注、光与声音应有编舞和层次。使用合适的 Timing/Spacing、Bezier Ease、Anticipation、Stagger、Follow Through、停顿、速度对比、父子级/约束；避免机械匀速、同步进场、突现与无意义 Bloom。转场优先空间、遮挡、动作及尺度连续，而非全靠 Fade。
- 有口播按真实音频/文本时间戳与呼吸节奏安排；没有则用分镜估时。镜头/段落/关键事件设置可移动 Marker，调整时能整体跟随，不用大量逐帧硬编码。时间线与预览/导出保持一致；拖动到同一时刻应能重现状态。
- **差点控件：** 可调的高价值参数尽量外露，常用 5–8 项前置（素材替换、主体、速度、强度、Camera、颜色等），高级参数分组折叠；全中文，专业英文附中文解释。直接调整应尽可能实时反馈；必须重渲的参数明确标识。动画与用户调整量尽量分离，不用控件数量替代设计质量。
- **审美门槛：** 构图、字形、比例、反射材质、层级、真实结构和运动必须达到目标参考的效果；不能以“模型可以转/工程能跑”算完成。复杂 AI/CGI 优先把场景与关键帧做好，再安排必要的可靠运动。

**交付当前镜头：** 可编辑工程路径、关键帧与短预览、实际检查结果、仅列本轮修改内容、未解决的真实问题。修改后核对未授权区域和工程可重新打开。
