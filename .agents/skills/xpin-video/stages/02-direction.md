# 02｜需求、参考与资产

**目标：** 确认当前任务的事实依据、视觉方向与可用素材。信息齐全直接推进；只集中询问阻塞问题，尽量三轮内定方向。把自然语言需求转换为专业术语，检索成熟参考与实现。

区分三种输入：**Truth（事实与结构证据）/ Reference（视觉与动态参考）/ Asset（可用文件和源码）**，分别核实，不以概念画面代替事实依据。

- **风格与 Motion：** 按镜头叙事目的、动作机制寻找少量高相关的成片、动态案例或灵感卡，提炼构图、材质、运动路径和节奏，再为当前内容重新设计。涉及运动时查看真实动态；涉及实现时核对源码。需要收藏时记录来源、关键机制和可复用部分。
- **真实素材：** 产品、人物、发布会及史实优先官方或原始来源，核型号、版本、画质、使用许可和实际可获得性。区分事实证据与画面素材；交给剪辑时标明对应口播、动作落点和必要处理。
- **现成资产：** 优先复用已有模板、用户文件、官方或授权明确的模型、图标、材质与开源资源；按实际用途核格式、质量、零件层级、动画、依赖和许可。硬件解构须先核对具体型号、零件结构及装配关系，区分可考证的物理结构与功能示意。混合素材保持统一的视觉和尺度关系。
- **独立元素：** 需要单独合成或控制的主体，保留适用的透明通道、分层、轴心、视角及比例。文字和标识尽量可编辑；真实产品细节依据可信参考。
- **AI 视频：** 先明确关键画面和主运动；复杂连续动作按镜头和剪辑节奏分段生成，关键几何、数据及文字采用可精确控制的制作方式。

## 封面（需要时）

从内容提炼一个明确卖点，使用真实可信的产品主体和清楚的视觉关系组织构图。按交付类型制作底图、独立合成元素或完整封面；优先保持主体准确、图文可编辑及合成空间。用户指定的视觉风格优先。多画幅分别设计，检查缩略图辨识度、标题空间与裁切。

## 视觉锚点与可行性

视觉复杂任务先确认构图、主体关系、材质光线和关键动作。**需要生成关键帧图或封面图时，先提供可复制的生图 Prompt，再生成图片**；用户要求直接出图时，展示 Prompt 后立即执行；已确认的 Prompt 和画面直接沿用。

技术难点先核对关键资产、可用工具、可编辑性和实现路径。当前镜头只记录必要的：`目的｜参考与素材｜画面和主动作｜时长/节奏｜锁定项｜验收`。
