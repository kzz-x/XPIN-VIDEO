# 02｜需求、风格、参考、素材与元素

**目标：尽量三轮内锁定方向、参考和执行方案。** 缺口集中问关键问题，已知不再问；信息齐全直接推进，不为凑轮次增加确认。用户用大白话描述，AI 主动翻译为专业中英文术语及同义词（Hairline / X-Ray / Exploded View / Match Cut 等），反向检索成熟案例。

先分清 **Truth（事实与结构证据）/ Reference（设计、真实动态）/ Asset（可用文件与源码）**，可从不同来源取得，不能用漂亮画面替代事实依据。

- **风格与 Motion：** 有可读灵感卡时按叙事功能、动作机制、镜头关系匹配，否则找成熟成片、发布会、专业作品与开源案例。选 1–3 个，分别分析构图/材质、路径/节奏、结构事实，明确**借什么、不借什么**，不要平均混搭。收藏夹、拼贴、AI 概念图、海报和视频截帧只是线索；没看原片不编动作/速度/时间码，没核源码不称可复刻。用户希望沉淀参考时，记来源、镜头位置、动作/材质/技术命门、源码（如有）、失败坑、可替换项和未核项，去重留简短灵感卡；按当前内容重新导演，不照搬。
- **真实素材：** 产品、品牌、发布会、人物、史实先找官方/原始源，再找可靠媒体和专业素材库。按「对象＋动作/角度＋场景」检索，核真实型号、日期、版本、画质、水印和可下载性。**素材画面不等于事实信源，公开可看不等于获准使用**；明确商用、改编、署名、平台与授权状态，不靠遮水印规避。交剪辑时记录口播/动作落点和裁切/抠图需要；未取得不称已下载。用户只要真实素材时不生成代替。
- **现成资产：** 自有模板/资产 → 用户文件 → 官方 PNG/SVG/Logo/模型 → 授权清楚的图标、3D、Lottie、HDRI、材质与开源代码，优先搜中英文同义词。核真实格式、零件拆分、Clip、贴图、分辨率、版本与许可，标明已取得/候选/待补；App 图标需核当前官方版本。硬件解构先核具体型号、真实零件与装配关系，再选择可独立控制的三维资产；物理结构和内部功能示意分别标识。Iconify/Lucide/Simple Icons、Poly Haven/ambientCG、现有 Hairline/X-Ray 和 GSAP/Remotion 等只是按需入口，不是强制技术栈。混合素材须统一线宽、材质、尺度及运动语言。
- **独立元素：** 没有合适资产再制作/生成；明确身份、视角、尺寸、材质、光线、Alpha、零件层级和锚点，多元素共用机位/比例便于合成。真实产品结构不可编造；科普抽象应标「示意」。主体、前景、阴影尽量可分层；棋盘格不等于真 Alpha，组图不等于独立素材。准确文字/Logo 放后期可编辑层。
- **AI 视频片段：** 先锁静帧；复杂连续运动用入场/主画面/变化/出场等少量关键帧分短段制作、剪辑衔接，不赌单次长生成。AI 擅长场景与简单可靠运动；复杂准确动作、数据和字交给可编辑制作，概念 CGI 不冒充实拍。

## 封面（仅用户要求时）

- **卖点与交付：** 从标题/结论提炼一个卖点、一个主体（或有关系的主体组）、一处有事实依据的视觉冲突和清楚的阅读路径；不靠无依据的爆炸/破碎制造噱头。先分清要**无大标题底图、可拆分 PS 素材还是完整封面**；默认硬件封面优先真实产品素材＋人工 PS 编辑合成感，AI 负责背景、材质、光影和局部元素，而非一张通体光滑的科幻 CGI 图；用户指定其他风格优先。
- **产品与版式：** 具体型号先用用户/官方真实多角度图锁定比例、颜色、镜头/接口、Logo 与结构；无法准确还原的视角优先做背景/示意占位，留给后期 PS 换真产品，绝不把猜测外观当真。用抠图、蒙版遮挡、前后层级、统一光影与克制纹理组织主体，避免无意义 HUD、霓虹和满屏装饰。标题区按真实字数/用户示意安排，背景低干扰但自然延伸，不强制居中、固定底部比例或左上角 Logo 区；大标题与频道 Logo 留后期，允许真实机身标识及少量准确小标签，不生成假字/伪参数。
- **提示词与验收：** 出图前先给可复制 Prompt，明确真实主体来源/PS 替换策略、构图裁切、层级、材质光线、画幅、标题区和禁项。要求双版时分别设计 **16:9 与 3:4**，不是一图硬裁；用缩略图及真实标题叠字预览检查主体辨识、视觉冲突、标题可读性和遮挡，预览文字不烘焙进底图。修改只动失败部分，保留已确认设计。

## 视觉锚点与可行性

中高复杂度先锁 Hero 关键帧的构图、信息层级、空间、材质和布光。**关键帧先 Prompt 后图片：** 先给一段可直接用于 Banana/生图模型的精简提示词，明确主体与场景、构图机位、材质光线、风格、画幅及关键保留/避免项；用户确认或修改后再出图。明确要求直接生图时，也先展示将用的 Prompt 后直接生成，不重复追问；已批准的 Prompt/关键帧直接复用。事实以真实证据为准。高成本效果补一个 **Technical Anchor**：检查现有工具、关键资产、真实可编辑性、最难的视觉机制和备用路线；规则化可验证任务可直接交 AI，审美/复杂 Graph 先锁关键意图。做不到就先调整方案，不在制作中悄悄缩水。

每镜交一张短卡：`目的｜参考/资产缺口｜视觉与主动作｜关键帧｜时长/Marker｜锁定项｜验收`。默认一套推荐、必要时一个备选；只让用户补真正阻塞的内容，不要求用户自己提供专业名词。
