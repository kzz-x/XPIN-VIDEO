# 02｜需求、风格、参考、素材与元素

**目标：尽量三轮内锁定可执行方案。** 已知信息不再问；仅当重要偏好或缺失素材确实影响结果时，用一组简短问题确认。用户只说大白话时，AI 自行识别专业中英术语与同义词（Hairline / X-Ray / Exploded View / Morph / Match Cut 等），反向找成熟方案。

## 先判断需要什么

- **风格/运动参考：** 主动找优秀商业成片、发布会、动效视频、专业作品和最新开源案例；区分视觉（构图、材质）、动作（路径、节奏）与结构（身份、真实关系）。选 1–3 个有用参考，说明借鉴点；有源工程/开源代码时优先理解真实做法。提炼 3–5 个可观察的视觉特征（构图、镜头、节奏、材质、字体），不拿「高级科技感」当规格。
- **真实素材：** 产品、品牌、发布会、工厂、人物、史实优先官方及原始来源，随后专业素材库/可靠媒体。区分「画面候选」与「证明文案的数据来源」；核实型号/版本、画面内容、时间和许可。没实际看视频就不编时间码，没下载就不说已下载。授权未知须标明；指定「只找真实素材」时不生成替代。
- **现成可用资产：** 优先当前工程/模板 → 用户素材 → 官方 PNG/SVG/Logo/模型 → 授权清楚的 3D、图标、Lottie、HDRI、材质、开源组件；搜索中文、英文和同义词。检查格式、结构拆分、分辨率、授权和是否可直接用于本镜头。按需优先查 Iconify/Lucide/Simple Icons、Poly Haven/ambientCG、现有 Hairline/X-Ray/Three.js 模板及成熟 GSAP/Remotion 组件；这些是候选入口，不是强制技术栈。
- **独立元素制作：** 找不到合适现成资产时再制作或生成（相当于「差点元素」能力，已内置）：明确身份、尺寸、视角、材质、光线、背景/Alpha、零件拆分与锚点；只要一个就做一个，多个元素共用机位/光照/尺度，便于 AE/Blender/HTML 独立控制。真实产品不可凭空补错结构；精确文字/Logo 单独叠加。概念元素要标「示意」。
- **完整 AI 片段：** 先锁静帧，再用明确动作/镜头约束生成片段；AI 负责高质量场景/简单可靠运动，精确数据、文字和复杂动作优先可编辑后期制作。不要把概念 CGI 当实拍。

## 定视觉锚点

中高视觉复杂度先定 Hero 静帧/关键姿态，参照构图、信息层级、空间结构、材质与布光；设计类 2D/3D/UI 可直接给**精简 Banana 提示词**，满意后制作。已有满意关键帧直接沿用，不重复生成。事实准确性以真实依据为准，不以生成图代替。

每镜执行卡只写：`内容目的｜参考和可用资产/缺口｜主视觉与关键动作｜关键帧｜时长/Marker｜不可改项｜验收`。默认交一套推荐方案，必要时 1 个差异化选项。只缺必要真实资产时明确让用户提供什么，而不是要求用户自己想专业名词。
