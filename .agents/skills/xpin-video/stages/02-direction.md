# 02｜需求收敛、风格、参考与资产（GPT）

**目标：尽量 3 轮对话完成「分镜→视觉锚点→可执行方案」**，不把三轮当强制审批。信息足够时直接给方案；只有影响效果的关键未知项才发**紧凑问卷**，可一次问 2–4 个：参考偏好/写实度、重点镜头、交付与可编辑方式、不可改项。已有回答不重问。

1. **反向检索。** 用户只需描述画面，主动识别视觉技术的中英文术语和同义词（如 Hairline、X-Ray、Exploded View、Match Cut）；搜成熟商业成片、近期案例、GitHub 可运行项目、可直接调用的库/模板。优先能复用的真实实现，而非只给灵感形容词。
2. **参考分工。** 找合适的参考图（构图/材质/灯光）、参考视频（动作/曲线/转场）、准确主体依据（产品/设备/结构）。挑 1–3 个有价值候选并标链接和具体借鉴点；优先官方→成熟案例/开源→素材库。静帧不能替代运动参考。
3. **资产先行。** 对精确模型、零件、SVG、Logo、图标、HDRI/贴图，先检索和核对格式、授权、可编辑性与真实结构。能直接用就用；找不到由**差点元素**按准确参考生成；需要人工提供时明确列出最小缺口及替换位置。**不得伪造具体产品结构、模型来源和授权。**
4. **视觉锚点。** 中高复杂度先做代表静帧/关键帧，必要时给简短 Banana 生图提示词（尤其设计类 2D/3D/UI/非写实 CGI）；真实准确性仍取官方素材。锚点锁定前不在错误方向上批量施工。
5. 给每镜一张**短执行卡**：`表达目标｜参考和可用资产｜构图/主体/关键动作｜首末或关键帧｜节奏/Marker｜锁定项｜验收标准`。只有真正需要才加技术要求。

**沟通原则：** 用问题收窄创意，不让用户替 AI 发明专业术语；能自己判断的自行判断。第一轮给全片和关键问题；第二轮给参考/资产/锚点；第三轮定稿和可交 Codex 的单镜任务。无须每轮产出巨大文档。
