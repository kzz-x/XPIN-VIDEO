# 02｜需求、风格、参考、素材与元素

**目标：少量关键沟通就能锁方案。** 已知不再问，只问真正影响结果的偏好/素材。用户用大白话描述，AI 主动翻译为专业中英文术语及同义词（Hairline / X-Ray / Exploded View / Match Cut 等），反向检索成熟案例。

先分清 **Truth（事实与结构证据）/ Reference（设计、真实动态）/ Asset（可用文件与源码）**，可从不同来源取得，不能用漂亮画面替代事实依据。

- **风格与 Motion：** 有可读灵感卡时按叙事功能、动作机制、镜头关系匹配，否则找成熟成片、发布会、专业作品与开源案例。选 1–3 个，分别分析构图/材质、路径/节奏、结构事实，明确**借什么、不借什么**，不要平均混搭。收藏夹、拼贴、AI 概念图、海报和视频截帧只是线索；没看原片不编动作/速度/时间码，没核源码不称可复刻。用户希望沉淀参考时，记来源、镜头位置、动作/材质/技术命门、源码（如有）、失败坑、可替换项和未核项，去重留简短灵感卡；按当前内容重新导演，不照搬。
- **真实素材：** 产品、品牌、发布会、人物、史实先找官方/原始源，再找可靠媒体和专业素材库。按「对象＋动作/角度＋场景」检索，核真实型号、日期、版本、画质、水印和可下载性。**素材画面不等于事实信源，公开可看不等于获准使用**；明确商用、改编、署名、平台与授权状态，不靠遮水印规避。交剪辑时记录口播/动作落点和裁切/抠图需要；未取得不称已下载。用户只要真实素材时不生成代替。
- **现成资产：** 自有模板/资产 → 用户文件 → 官方 PNG/SVG/Logo/模型 → 授权清楚的图标、3D、Lottie、HDRI、材质与开源代码，优先搜中英文同义词。核真实格式、零件拆分、Clip、贴图、分辨率、版本与许可，标明已取得/候选/待补；App 图标需核当前官方版本。Iconify/Lucide/Simple Icons、Poly Haven/ambientCG、现有 Hairline/X-Ray 和 GSAP/Remotion 等只是按需入口，不是强制技术栈。混合素材须统一线宽、材质、尺度及运动语言。
- **独立元素：** 没有合适资产再制作/生成；明确身份、视角、尺寸、材质、光线、Alpha、零件层级和锚点，多元素共用机位/比例便于合成。真实产品结构不可编造；科普抽象应标「示意」。主体、前景、阴影尽量可分层；棋盘格不等于真 Alpha，组图不等于独立素材。准确文字/Logo 放后期可编辑层。
- **AI 视频片段：** 先锁静帧；复杂连续运动用入场/主画面/变化/出场等少量关键帧分短段制作、剪辑衔接，不赌单次长生成。AI 擅长场景与简单可靠运动；复杂准确动作、数据和字交给可编辑制作，概念 CGI 不冒充实拍。

**封面仅在用户要求时：** 一个卖点、一个识别主体、一处视觉冲突；产品准确优先，缺真实外观先做可替换背景；16:9/3:4 分别排版和裁切，给后期标题留空间，避免假参数或错误大字烘焙。

## 视觉锚点与可行性

中高复杂度先锁 Hero 关键帧的构图、信息层级、空间、材质和布光；设计类 2D/3D/UI 可给精简 Banana 提示词。已批准的关键帧直接复用；事实以真实证据为准。高成本效果补一个 **Technical Anchor**：检查现有工具、关键资产、真实可编辑性、最难的视觉机制和备用路线；规则化可验证任务可直接交 AI，审美/复杂 Graph 先锁关键意图。做不到就先调整方案，不在制作中悄悄缩水。

每镜交一张短卡：`目的｜参考/资产缺口｜视觉与主动作｜关键帧｜时长/Marker｜锁定项｜验收`。默认一套推荐、必要时一个备选；只让用户补真正阻塞的内容，不要求用户自己提供专业名词。
