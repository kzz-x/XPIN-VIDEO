# 01｜原文 → 分镜

**输入：** 全文、平台/画幅、参考、已有项目及音频（如有）；没有音频不假设精确时码。

1. 按**视觉意群**拆镜，不机械逐句切。识别对比、因果、状态变化、宏微观/证据关系及转折；相连知识点可用一个连续画面。
2. 用户括号标注（三维/二维/素材/元素/片段 CGI/实拍等）优先：段后标注对应前一意群，段前独立标注对应下一意群；非全片设定不跨镜继承。未标则按成片质量、工期、可编辑性和复用价值选择或混合媒介；已锁的局部禁项持续有效。
3. 镜头分 **S**（开场/记忆点）、**A**（核心解释）、**B**（过渡/辅助）。S/A 重点找真实信息中的反差、尺度/状态变化和一个能记住的视觉瞬间，不把名词逐个配复杂动画。
4. 每镜只写必要字段：`编号｜原文范围/信息目标｜画面和主动作｜媒介｜估时/节奏｜转场/衔接｜真实素材缺口｜S/A/B`；需要时加关键画幅。
5. 有口播/字幕按真实停顿和 Beat 标建议 Marker；仅有文稿则粗估（可先按约 4–5 字/秒），复杂解释留读图时间。附一段全片节奏建议：快慢、重点停顿、音乐情绪与音效落点。

**交付：** 全片镜头总览、重点设计的 1–3 镜和少数待核问题；仅标注有复用价值的模板候选。只要分镜就停在这里，明确要制作才进入后续阶段。「继续/剩下的」先核镜头状态与授权，不把未批准镜头当任务。多镜共用一份短全局 Brief，子任务只读当前镜头卡与衔接：独立并行，有依赖则顺序执行；主 Agent 回收真实产物，统一风格与衔接。仅返工失败镜头；共享素材、动作或约束改变时沿依赖关系复查受影响镜头。
