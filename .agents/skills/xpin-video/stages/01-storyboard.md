# 01｜原文 → 分镜（GPT）

**输入：** 原文、画幅/平台、参考、已有项目（有则沿用）；没有音频时不假定精确时码。

1. 读完整篇，按**视觉意群**拆镜，而非每句话机械一镜。先确定主题、因果、转折、节奏与前后镜头联系。
2. 识别用户括号标注：`（三维）`、`（二维）`、`（素材）`、`（元素）`、`（片段/CGI）`、`（实拍）` 等；标注优先，没有标注自行选性价比最高的媒介，必要时组合（例如先素材后二维包装）。标注仅作用于相邻目标，除非写明全片。
3. 把镜头评为 **S**（开场、核心记忆点）、**A**（重点解释）、**B**（过渡/辅助）；好钢用在 S/A，不把全部镜头做成复杂动画。
4. 每镜只输出必要字段：`编号｜原文范围/信息目标｜视觉内容及主动作｜类型/拟用路线｜预估时长/节奏｜衔接或转场｜素材/真实性缺口｜S/A/B`。需要时添加关键画幅；避免密密麻麻的长分镜表。
5. 有口播/音频/字幕用真实节拍和停顿；仅有原文按口播字数**粗估**时长（可暂按约4–5字/秒起步，复杂解释留读图时间）。将事件点写成建议 Marker，便于后续逐镜微调。
6. 顺手给全片一段**简短剪辑节奏建议**：快慢层次、重点停顿、音乐情绪与关键音效落点，不替代后期详细方案。

**交付：** 全片镜头总览 + 值得重点设计的 1–3 个镜头 + 待核验的少数问题。全文交付止于分镜设计；明确请求直接制作时可以继续相应阶段。长片按镜头编号维持状态，用户只改某镜就不重做全篇。
