# 04｜审片、剪辑、声音与交付

**验收优先级：讲对 → 一眼看懂 → 审美/Motion 达到参考 → 可编辑与可导出。** 逐镜看结构、材质、构图、文字、真实性、动作层次；在 Marker 前后、动作峰值、停顿及首/中/末取关键帧，同时**播放真实视频**检查节奏、焦点、穿模、闪烁、跟随、遮挡和循环接缝。画面虽整齐但模板味重也算未达标；先修设计与主动作，不靠滤镜补救。

**剪辑与声音：** 通读文稿，先去口误、赘词和重复，以 A-roll/口播搭主时间线，再插真实素材、录屏、CGI/动效，最后调整字幕、声音与转场。依据关键词、停顿、呼吸与 Marker 定切点；重点/结论给停留，复杂信息留读图时间。音乐控制情绪起伏，音效对应真实出现、碰撞、组装、扫描等动作，保证人声可懂。跨镜保留主体/空间/运动方向，尤其宏观→微观→拆解重组的结构身份和方位。

**素材/录屏/字幕：** 实拍录屏前清桌面、关通知，核操作路径、画幅、文字可读性；按需指针高亮。事实与画面证据分开：概念 CGI 不称实拍，数据不偷换口径。PR 可用转录/切点/静音识别批量整理；字幕删无信息口头语、按语义断句、核专名/单位，**保留原时码与已锁文案策略**。

## 渲染与交付

1. **关键帧：** 少量代表帧对照参考，未达标不精渲。
2. **短预览：** 按目标镜头取 540–720p 低成本样片，尽量 ≤10 分钟；超预算就缩段、降低采样并说明。
3. **正式成片：** 用户批准或明确要求后再完整渲染；依交付要求选择 1080p/4K、fps、Alpha/色彩和音频规格。

**独立的三档画质选项：** 默认提供「快速 / 标准 / 高质量」（默认标准，低清短预览用快速）；按实际渲染器能力区别采样/抗锯齿、景深/运动模糊、光影精度与编码质量，不机械套固定参数，也不意味着必须生成三份视频。

渲前核画幅、fps、色彩、字幕安全区、容器/编码、音轨与输出路径；先**真实短段测速**，主动告知预计总耗时及估算不确定性，未实测只能粗估。正式片先本地输出并实际打开验证解码、帧数/时长、音画同步与画面，再传共享盘/NAS。HTML 录制还要核 DOM/SVG/WebGL、字体与混合层是否录进文件，不以改后缀冒充转码；锯齿/闪烁先修采样，不靠码率掩盖。

长渲染只有确认任务已真实启动、可脱离会话继续时，才交付后台任务 ID/日志或状态入口、输出路径、预计完成时间，让用户不必留在对话等待；无法后台运行则说明限制与恢复方式，不能空等或假称已启动。

**完成报告：** 路径、档位、**已核/失败/未测**与最多 3 个问题。按交付物核验源码构建、交互、GPU 画面、视频下载与实际解码、目标机器表现，并记录证据。审核只对应当前镜头及产物版本，返工需重审，旧版 PASS/截图不沿用；AI 片段核身份/数量/光源连续，元素核 Alpha/拆分，可编辑工程核改值生效和保存重开。只更新当前镜头状态。
