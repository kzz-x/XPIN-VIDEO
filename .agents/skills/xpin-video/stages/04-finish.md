# 04｜审片、节奏、声音与交付

**验收顺序：讲对 → 一眼看懂 → 像参考一样好看 → 真正可编辑/导出。** 先查当前镜头的主视觉、结构、排版、材质光照、Motion、镜头连续性和真实性。不要只看静帧：检查起/中/末、衔接、穿模、焦点、闪烁、标注跟随、遮挡与循环接缝；失败先修最重要问题，别叠滤镜。

**音画剪辑：** 口播关键词、停顿和呼吸控制切点；没有口播按估时，留读图停顿。音乐服务情绪与强弱，音效只打在出现、碰撞、组装、扫描、转场、结论等有因果的动作点，控制密度和人声可懂度。统一 Marker/Beat，方便 PR/AE 后期改速、挪节拍、接前后镜头；前后镜头不应各自无故重置运动状态。

## 输出顺序

1. **关键帧：** 几张代表静帧对照目标参考，没达标先不精渲。
2. **快速预览：** 只输出指定镜头/短样片，约 540–720p、低采样，目标计算用时不超过 10 分钟；超出就缩段或降低预览成本并告知。
3. **正式成片：** 用户批准或明确要求后才启动完整高质量渲染。

| 质量档位 | 默认目的 |
|---|---|
| 快速 | 540–720p / 简化特效 / 审动态与音画，优先 ≤10min |
| 标准 | 常用 1080p / 目标帧率 / 合理抗锯齿、采样与降噪 |
| 成片 | 实际交付分辨率/帧率，按需 4K、景深/运动模糊、准确色彩/Alpha/音频与高质量编码 |

渲染前核查画幅、fps、色彩、文字安全区、编码/容器、音轨、输出位置。用实际短段测速估算总帧时长；没有数据就只给**粗估范围**，不能伪称实测。导出后要打开真实文件，检查可播放、帧数/时长、音画同步和画面，而不是只看「完成」通知。

**开启长渲染后不要傻等。** 后台渲染只在已确认脱离会话后仍持续的情况下启动并记录任务/日志/输出位置与 ETA，随后结束当前轮次；不支持可靠后台则如实告知启动与恢复方式。不能说「后台已经在渲染」却实际没有启动。

完成时只报：文件/工程路径、渲染档位、实测与未测、最多三个待修问题；更新单镜状态即可。
