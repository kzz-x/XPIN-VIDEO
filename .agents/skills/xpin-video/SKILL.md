# 差点视频 · XPIN Video

**目标：用最短有效路径做出真正达到参考水平、可继续修改的专业视频。** Art Direction / 叙事 / Motion / 视觉完成度优先；工程规范是护栏，不是创意模板。

## 不变的原则

1. **设计全局，制作局部。** 先掌握全文和镜头衔接，再按单镜头/小批次制作；关键镜头（Hero Shot）先达标，不让批量生产稀释质量。
2. **Reference + Asset First。** 主动把用户的大白话翻译成专业中英术语，搜索新鲜成熟案例、真实视频、开源实现、现成模板与准确资产；缺关键事实不编造。风格参考、动作参考和真实主体依据各司其职。
3. **锁结果，不锁过程。** 锁原文事实、用户标注、已确认设计、准确资产、交付与验收；让 Codex 自主决定技术路线、实现细节和 Motion。提示词短而准：首次制作默认 P2 导演模式；探索用 P1；精确修改用 P3。
4. **先画面后工程。** 复杂视觉先锁关键帧/参考图；优先复用成熟方案。创意可以突破模板，但不能以特效堆砌掩盖构图、结构和运动缺陷。
5. **保护已有成果。** 修改现有工程前先读取真实状态，并**在其他位置复制完整备份**，保持原文件位置与路径不变；只动授权范围，回归检查未修改部分。
6. **可编辑、可预览、可验证。** 高频且可能返工的参数优先做实时控件；动画按口播/估时设置 Marker。默认先关键帧→轻量视频预览，不自动完整精渲；完成后提供三档渲染和预计耗时。执行、测试、交付状态必须真实。

**路由：** 三维/二维可选 AE、Blender、HTML/Three.js/VibeMotion 等；真实素材→差点素材；独立模型/SVG/图标→差点元素；概念镜头→差点片段。到实际操作时才按需进入专用仓库的 Mini/Full，不把它们整套加载进本 Skill。

**会话续接：** 多镜头项目用简洁的项目总表 + 单镜头卡持久化「当前阶段／版本／已锁定项／待办／路径／下步动作」；只更新变化项，不靠聊天上下文猜进度。用户仅请求设计时不擅自开始制作；明确「直接制作」时跳过多余确认，不跳过必要的真实性与备份检查。
