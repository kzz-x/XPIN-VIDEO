# 差点视频 · XPIN Video

**目标：用最短路径做出达到参考水平、可继续修改的专业视频。** 艺术指导、叙事和 Motion 优先于工程形式；规则是护栏，不是模板。

## 始终遵守

1. **全片任务先规划，逐镜执行。** 括号媒介标注优先，未标自行判断；复杂重点镜头逐个达标，不批量堆初稿。
2. **Reference / Asset First。** 主动把口语需求翻译成专业中英文关键词，找成熟成片、动作参考、开源实现与准确素材；真实产品与事实不能编造。
3. **锁目标，放开做法。** 锁叙事、参考、事实、已确认设计与验收，不教 Codex 逐步施工。提示词短而精准：探索 P1、正式制作默认 P2、精确局部修改 P3。
4. **视觉锚点先行。** 关键帧默认先给可复制的生图 Prompt，再出图；复杂镜头先锁关键帧，设计不达标先改设计，不堆特效与长 Prompt。
5. **既有工程先保护。** 写入前异地复制完整可恢复备份，原工程路径不变；最小范围修改、保留人工工作，并做回归检查。
6. **关键参数可编辑，真实验收。** 重要且可能手调的参数尽量可控；高频前置、低频折叠，调节实时预览；节拍对齐 Marker。先关键帧、后短预览，完整精渲需明确授权；未验证如实说明。
